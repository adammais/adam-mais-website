AI Question Bank Manager

Description

  • Adam Mais

Developed a full-stack educational platform to import, manage, and render PrairieLearn assessment questions. Built with the MERN stack, Ulti-Quest features a hybrid Node.js/Python rendering engine capable of emulating PrairieLearn’s custom HTML elements in a browser. Key functionalities include a zip-file uploader for automated question imports, AI-powered tag generation, and a hierarchical tagging model for intuitive question categorization.
